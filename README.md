## 📖 About

Desert Temple Finder predicts desert pyramid locations from the world seed, showing TNT trap coordinates and loot room access path.

## ✨ Features
<a name="features"></a>

- **All Pyramids Listed** — every desert temple sorted by distance.
- **TNT Trap Coords** — pressure plate position to avoid.
- **Loot Room Access** — optimal dig path to the chest room.
- **Map Markers** — pins on minimap.
- **HUD Arrow** — points to nearest pyramid.
- **Toggle Key** — quick on/off.
